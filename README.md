# Simplified Raft Consensus Simulation

This example simulates a highly simplified version of the Raft consensus algorithm's core principle: achieving agreement among distributed nodes. It demonstrates how a designated leader proposes a value, followers acknowledge it, and the value is committed across the system only after a majority of nodes have accepted the proposal. This illustrates the fundamental concept of reliable agreement in a distributed system.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
